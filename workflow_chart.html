SCI-Lab Badge Software — Pipeline Overview

Voice Activity & Meeting Productivity Analysis from Wearable Badges

Data
Collection
BLE Badge Scanning & Data Collection
data_collection.py
Scans for known badge MAC addresses via Bluetooth LE → connects to all detected badges in parallel → streams Sound Level, RSSI, Acceleration, GR in real-time → saves every reading to a unified CSV. Person names are assigned to each badge at startup.
📄
badge_data/AllBadges_data_TIMESTAMP.csv
Raw timestamped sensor readings from all badges in one file
Optional
Stitching
Multi-Session Stitcher (optional)
badge_stitcher.py
Merges multiple session CSV files into one, reconciles badge→person mappings across sessions, and adds a Session column for traceability.
Activity
Labeling
Manual Labeler
badge_data_processor.py
Interactive GUI: plots sensor signals, user drags time regions and presses A (active) / N (not active). Exports per-badge labeled CSVs.
— OR —
Auto Labeler
auto_label.py
Peak-based speech detection: normalises sound & acceleration, compares badges in 500 ms bins, applies majority-vote smoothing → labels each row active / not_active & identifies the speaker.
↳ label_comparison.py can diff manual vs auto labels to evaluate auto-labeler accuracy
📄
processed_data/auto_label/<meeting>.csv
Per-row labels: auto_activity_label, auto_speaker, norm_sound, norm_accel, speech_score, time_bin
Feature
Extraction
Meeting Feature Extractor
feature_extraction.py
Aggregates labeled data into three feature tables: meeting-level (speaking ratio, silence ratio, turns/min, turn equity, Gini coefficient…), participant-level (per-person talk share, turn count…), and window-level (rolling 5-min windows). Also generates meeting_visualizer.py charts.
📄meeting_features.csv— one row per meeting
📄participant_features.csv— one row per (meeting × participant)
📄window_features.csv— one row per (meeting × time window)
Weka
Export
Weka Dataset Exporter
weka_exporter.py
Joins the three feature tables into one flat meeting-level dataset. User labels each meeting's effectiveness (low / medium / high). Writes a clean .csv and an .arff file ready for Weka. Results can be visualised with weka_visualizer.py.
📊
weka_outputs/meeting_dataset.arff
Meeting-level feature matrix with effectiveness class labels — loaded directly into Weka
ML
Analysis
Weka Machine Learning
Weka (external tool)
Loads the ARFF dataset and runs classifiers (e.g. Random Forest, Naïve Bayes, J48) to predict meeting effectiveness from interaction features. Cross-validation & attribute selection performed in Weka GUI.
